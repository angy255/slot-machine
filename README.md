# 🎰 🐠 Journey Underwater Slot Machine

Spin the reels with sharks, eels, mermaids and more in this fun, **ocean-themed slot machine**!

---

## ✨ Features
- 🎲 Play a classic 3-slot machine game with an **underwater twist**  
- 💰 Bet **10 or 50 coins** each spin  
- 🫧 Bubbling water sounds with every bet  
- 🎉 Match all 3 slots to win:  
  - Background changes to celebrate 🏴‍☠️ 
  - Special congratulatory audio plays 🐋
  - Player earns more coins to keep playing  
- 📱 Fully responsive design

---

## 🛠️ Built With
- **HTML5** – structure  
- **CSS3** – styling and responsive design  
- **JavaScript** – interactive logic

---

## 🎯 How to Play
1. Start with coins  
2. Click on your bet buttons (10 coins or 50 coins) to spin 
3. 🎉 Match all 3 slots to win pirate treasure & celebrate   
4. 🪙 Run out of coins → game over  

---

## 📦 Installation & Setup
1. Clone this repository:
     
  ```bash
  git clone https://github.com/your-username/slot-machine.git
  ```
2. Navigate into the project folder:

  ```bash
  cd slot-machine
  ```
3. Open index.html in your browser.
